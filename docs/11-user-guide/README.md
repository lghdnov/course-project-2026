# Руководство пользователя msocial & likma

Данный документ содержит пошаговые инструкции по настройке, авторизации, управлению профилем, работе с публикациями и комментариями, а также инструкции по деплою и запуску приложения.

---

## 1. Подключение к серверу msocial и авторизация

Клиентское приложение **likma** является Matrix-клиентом с расширенными социальными функциями, предоставляемыми бэкендом **msocial**.

### Шаг 1: Настройка подключения к msocial

1. Откройте приложение **likma** (веб-версию или десктопное приложение).
2. Перейдите в раздел **Настройки** (Settings) -> **Matrix Social**.
3. В поле **API Base URL** укажите адрес вашего бэкенд-сервера `msocial` (по умолчанию для локального запуска: `http://localhost:8080`).
4. Нажмите кнопку сохранения конфигурации. На экране отобразится статус подключения (например, `Connected` при успешном соединении).

### Шаг 2: Авторизация в Matrix и msocial

1. На экране авторизации введите адрес вашего Matrix-домашнего сервера (homeserver) и учетные данные (логин и пароль).
2. При успешном входе в Matrix клиентское приложение автоматически:
   - Запросит OpenID-токен у Matrix-сервера.
   - Выполнит запрос к API `msocial` (`POST /api/v1/auth/login`) для обмена OpenID-токена на JWT-токен авторизации msocial.
   - Инициализирует сессию пользователя.

## 2. Управление профилем

Раздел профиля позволяет управлять персональными данными и настраивать медиа-контент.

### 2.1. Просмотр профиля

Для перехода в свой профиль кликните по вашему имени или аватару в интерфейсе. В профиле отображаются:
- Аватар и имя пользователя.
- Уникальный Matrix ID (например, `@username:matrix.org`).
- Персональные данные: дата рождения, адрес проживания, текущий статус.
- Любимый аудиотрек со встроенным плеером.
- Личная лента публикаций.

### 2.2. Редактирование личной информации

1. Нажмите кнопку **Редактировать профиль** (или иконку карандаша).
2. Заполните или обновите следующие поля:
   - **Отображаемое имя (Display Name)**.
   - **Статус** (краткая информация о себе).
   - **Дата рождения**.
   - **Адрес**.
3. Сохраните изменения. Данные будут автоматически обновлены в базе данных `msocial`.

### 2.3. Загрузка любимого трека

Вы можете установить музыкальную композицию, которая будет проигрываться в вашем профиле:

1. В режиме редактирования профиля найдите поле загрузки аудио.
2. Выберите аудиофайл в формате MP3 со своего устройства.
3. Сохраните настройки. Аудиофайл загрузится на сервер и станет доступен для прослушивания через встроенный плеер для всех посетителей вашего профиля.

## 3. Публикации (Лента новостей)

Лента новостей объединяет публикации пользователей социальной сети.

### 3.1. Создание поста

1. Перейдите на страницу **Social** (Лента публикаций).
2. В верхней части страницы найдите форму создания поста.
3. Введите текст публикации.
4. (Опционально) Нажмите кнопку прикрепления медиафайлов и выберите изображения или другие файлы для добавления к посту.
5. Нажмите кнопку **Опубликовать**.

### 3.2. Просмотр ленты
- В ленте отображаются посты в хронологическом порядке.
- Каждая карточка поста содержит информацию об авторе (аватар, имя), дату публикации, текст, прикрепленные медиафайлы и кнопки взаимодействия (комментарии, поделиться).
- Встроенный слайдер изображений позволяет пролистывать несколько прикрепленных картинок.

### 3.3. Редактирование и удаление публикаций
- **Редактирование**: для изменения текста своего поста нажмите на иконку меню (три точки) на карточке публикации, выберите «Редактировать», внесите изменения и подтвердите сохранение.
- **Удаление**: для удаления поста откройте то же меню и выберите «Удалить». Публикация и все прикрепленные к ней комментарии будут удалены безвозвратно.

---

## 4. Комментарии

К любому посту в ленте можно оставить древовидные комментарии.

### 4.1. Просмотр обсуждения

Нажмите на кнопку комментариев на карточке публикации. Вы будете перенаправлены на страницу поста с детальным отображением его текста, медиафайлов и полного дерева комментариев.

### 4.2. Добавление комментария
- **Обычный комментарий**: введите текст в поле ввода внизу страницы и нажмите отправить.
- **Ответ на существующий комментарий**: нажмите кнопку «Ответить» под конкретным комментарием. Появится поле ввода ответа. Ваш комментарий отобразится со смещением в древовидной структуре.

### 4.3. Редактирование и удаление комментариев
- Вы можете редактировать текст своих комментариев в течение сессии.
- Для удаления своего комментария нажмите кнопку «Удалить» рядом с ним. Если у удаляемого комментария были ветки ответов, структура дерева будет скорректирована в соответствии с правилами хранения связей.

## 5. Инструкции по установке и деплою приложения

Подробная информация о развертывании находится в разделе [docs/10-deployment](file:///Users/dimasik/Documents/Projects/CourseProject-2026/docs/10-deployment/deployment.md). Ниже приведены основные способы запуска системы.

### Вариант А: Локальный запуск для разработки

#### 1. Запуск СУБД PostgreSQL (через Docker)

```bash
docker run -d --name msocial-postgres \
  -e POSTGRES_DB=msocial \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -p 5432:5432 \
  postgres:15-alpine
```

#### 2. Запуск бэкенда msocial

```bash
cd msocial
./gradlew bootRun
```

Сервер будет доступен по адресу: `http://localhost:8080`.  
Интерактивная документация API (Scalar UI): `http://localhost:8080/scalar`.

#### 3. Запуск фронтенда likma

```bash
cd likma
npm install
npm run dev
```

---

### Вариант Б: Запуск в Docker

Сборка и запуск бэкенда в контейнере:

```bash
cd msocial
./gradlew bootJar
docker build -t glitchcat/msocial:local .
docker run -d -p 8080:8080 \
  -e DB_URL=jdbc:postgresql://host.docker.internal:5432/msocial \
  -e DB_PASSWORD=postgres \
  -e JWT_SECRET=your-secret-key \
  glitchcat/msocial:local
```

---

### Вариант В: Деплой в Kubernetes (через Helm)

Для развертывания в кластере Kubernetes выполните следующие команды:

```bash
# Обновление зависимостей чарта (включая PostgreSQL)
helm dependency update ./msocial-helm

# Установка чарта в кластер
helm install msocial ./msocial-helm \
  --set postgresql.enabled=true \
  --set postgresql.auth.password=SuperSecretPassword123 \
  --set app.jwt.secret=MyVeryStrongJWTSecretKeyForProd
```

Для удаления релиза используйте:

```bash
helm uninstall msocial
```
